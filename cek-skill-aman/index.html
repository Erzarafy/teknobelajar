3 Cek Sebelum Install Skill AI

Skill AI berjalan dengan akses file yang sama seperti agent yang memakainya, jadi satu skill nakal bisa membaca file di laptopmu. Cek dulu sebelum install. Daftar ini dari video Jangan Asal Install Skill AI, Ini Cara Ceknya di channel TeknoBelajar.

  1. Baca SKILL.mdLihat perintah apa yang dijalankan dan file apa yang dibaca. Kalau ada yang aneh dan tidak berhubungan dengan fungsinya, jangan install.
  2. Periksa repoSiapa pemiliknya, kapan terakhir diperbarui, dan apakah issue terbuka dijawab. Repo yang dirawat pemiliknya jauh lebih aman.
  3. Coba di tempat terpisahSebelum dipakai untuk data penting. Kalau skillnya berulah, yang kena cuma tempat cobanya, bukan file aslimu.
